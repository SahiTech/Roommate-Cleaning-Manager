## Product goal
Provide a simple shared cleaning-duty workflow for roommates:

1. A recurring duty is assigned according to the rotation.
2. The assigned roommate receives a reminder.
3. The roommate completes the cleaning.
4. The roommate confirms completion.
5. The system records the completion time.
6. The next scheduled roommate receives the appropriate notification.
7. Admin can review current status and history.

## MVP
- Admin/room leader
- Roommate accounts
- Recurring schedules
- Automatic rotation
- Duty status: pending, active, completed, overdue, missed
- Confirmation timestamp
- Dashboard
- History
- Mobile-first responsive UI
- PWA support
